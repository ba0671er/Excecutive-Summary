# oem-process.md / OEMプロセスマニュアル

> OEMコーディネーターが中心で参照。自社ブランド製造のプロジェクトマネジメント標準。

---

## 1. OEMの全体フロー

```
企画 → 市場調査 → 仕様策定 → 工場選定 → サンプル →
承認 → 量産発注 → 生産管理 → 検品 → 輸送 → 入庫 → 販売開始
```

所要期間目安: 食品類3〜6ヶ月、雑貨類2〜4ヶ月、アパレル類3〜5ヶ月。

---

## 2. 各フェーズの成果物

| フェーズ | 成果物 |
|---------|--------|
| 企画 | ブランド・商品コンセプトシート |
| 市場調査 | `templates/product-research.md` 準拠 |
| 仕様策定 | 仕様書ドラフト（素材/寸法/色/印字/梱包） |
| 工場選定 | 相見積比較表、候補評価シート |
| サンプル | サンプル評価レポート |
| 承認 | 最終仕様書、発注書 |
| 量産 | 進行ガント（マイルストーン） |
| 検品 | 検品基準書、検品結果 |
| 輸送 | インボイス、輸送書類 |
| 入庫 | 入庫検品、不良率記録 |

---

## 3. 仕様書に必ず含める項目

1. 商品名・品番
2. 素材（成分比率）
3. 寸法（公差含む）
4. 色（色見本番号またはPantone等）
5. 仕上げ（表面処理、質感）
6. 印字・刻印（ロゴ・ロット番号）
7. パッケージ仕様
8. 内箱・外箱仕様
9. ラベル・表示義務事項
10. 検品基準（AQL等）

---

## 4. 工場選定の評価シート

| 軸 | 配点 | 評価内容 |
|----|------|---------|
| 品質 | 30 | サンプル完成度、検品体制 |
| 価格 | 20 | 単価、ロット、支払条件 |
| 納期 | 15 | リードタイム、遵守実績 |
| 柔軟性 | 15 | 小ロット対応、仕様変更可否 |
| コミュニケーション | 10 | レス速度、提案力 |
| 物語性 | 10 | つくりての思想、背景 |

---

## 5. サンプル評価の標準

- 受領時のパッケージ状態
- 実寸計測（仕様との差）
- 重量計測
- 外観検査（傷・色ブレ・印字の乱れ）
- 機能検査（商品特性に応じて）
- 同等サンプルで複数点評価（ブレを見る）

評価結果は写真つきで記録し、工場へフィードバック。

---

## 6. 量産管理の着眼点

- 進捗チェックポイント（素材手配 / 生産開始 / 50%完了 / 検品 / 出荷）
- 不良対応のエスカレーションフロー
- 変更管理（仕様変更は必ず書面で）
- 支払タイミング（契約通りか）

---

## 7. 検品基準

- 全数検品か抽出検品（AQLレベル）かを事前に合意
- 不良区分: 重欠陥 / 軽欠陥 / 外観のみ
- 不良発生時の費用負担ルール

---

## 9. 運用ルール

- 各OEM案件ごとに `outputs/procurement/oem/<ブランド>_<商品>/` フォルダを作る
- 成果物・やりとり・決定事項をすべて記録
- 完了案件の振り返りを本ファイル or 別ファイルに追記
