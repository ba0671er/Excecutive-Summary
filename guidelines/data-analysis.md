## 1. 分析の基本フロー

```
問い → 仮説 → データ → 発見 → 解釈 → 示唆 → アクション
```

**問いから始めない分析は、単なる数字の羅列になる。**

---

## 2. EC売上の基本分解

```
売上 = アクセス × CVR × 客単価
     = 新規売上 + リピート売上
     = (新規顧客 × 新規単価) + (リピーター × 購買頻度 × 客単価)
```

どこを動かすと売上が動くか、必ず構造化して見る。

---

## 3. 代表的なフレーム

### RFM分析
- Recency: 最終購入からの日数
- Frequency: 購入回数
- Monetary: 累計購入金額
- 5×5×5 で125セグメント、運用上は上位/中位/下位に集約

### コホート分析
- 初回購入月でグループ化し、以降の継続購入率を見る
- F2転換率（1回→2回目）は特に重要

### ファネル分析
- Impression → Click → LP → カート → 購入
- 各ステップの離脱率を出し、最大のリーク箇所を特定

---

## 4. 指標を見るときの原則

1. **母数必須**: 率は母数とセットで出す
2. **期間比較**: 前期・前年・移動平均で見る
3. **分布を見る**: 平均だけで語らない（中央値・分布）
4. **セグメント**: 全体平均はウソをつく
5. **因果と相関**: 相関を因果と混同しない

---

## 5. 広告特有の指標

- **寄与売上 vs 広告経由売上** の違いを理解
- **アトリビューション**: ラストクリックだけで見ない
- **新規獲得 vs 既存売上**: 指名KWでの数字に注意

---

## 6. レポートの構造（テンプレ）

```
1. サマリ（3行以内）
2. KPI一覧（前期比含む表）
3. ハイライト（良かった/悪かった）
4. 要因分析（どのセグメント・どの施策が効いた）
5. 示唆と次の打ち手
6. 付録（生データ）
```

---

## 7. NG分析パターン

- 「〇〇が増えました」だけで終わる（要因・構造がない）
- 直近値と過去1点を比較（移動平均を見ない）
- サンプル数無視の断言
- グラフの目盛り操作で誇張
- 平均値依存（中央値・分布を見ない）
