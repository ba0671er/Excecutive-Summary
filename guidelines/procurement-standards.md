# procurement-standards.md / 仕入れ基準マニュアル

> 商品リサーチャー、OEMコーディネーター、ストアオペレーターが参照。
> 「何を / いくらで / どれだけ仕入れるか」の判断基準。

---

## 1. 仕入れ可否のMUST条件

| 項目 | 基準 | 備考 |
|------|------|------|
| 想定粗利率 | 最低30%以上（原則） | 物販ジャンル一般 |
| 想定月販個数 | 10個以上見込める | それ未満は要相談 |
| 初回仕入ロット | 想定月販の1〜2ヶ月分以内 | 在庫リスク抑制 |
| 差別化余地 | 類似品との明確な差が言える | 差別化ゼロは不採用 |
| 法規制クリア | 輸入/食品/医療雑品の規制を事前確認 | `compliance.md`参照 |
| PLリスク | 想定事故リスクと対応可能性 | 高リスク品は原則不採用 |

## 2. 原価計算の型

```
仕入原価 = 商品原価 + 送料 + 関税・消費税 + 検品コスト + 保管料
売価 = 仕入原価 × (1 + 想定粗利率) + モール手数料 + 決済手数料 + 送料
```

モール手数料は各モールごとに違うため、売価は **モール別に試算** する。

## 3. リサーチ軸（標準）

1. 市場規模（月間検索数 / 類似商品レビュー数総和）
2. 競合状況（上位商品数、価格帯、星評価）
3. トレンド性（上昇 / 安定 / 下降）
4. 差別化余地（機能・デザイン・価格・物語）
5. 仕入れ難易度（MOQ・納期・支払条件）
6. 法規制（輸入・食品・電波法等）

---

## 4. 仕入れ先の評価軸

| 軸 | 見るポイント |
|----|-------------|
| 安定性 | 創業年数、納期遵守の評判、取引実績 |
| コミュニケーション | レス速度、質問への説明の丁寧さ |
| 柔軟性 | 小ロット対応、仕様変更への姿勢 |
| 物語性 | つくりての思想・背景（つながるECの価値と合致するか） |
| 支払条件 | 初回 / 継続時の条件、前払・後払い比率 |

---

## 5. サンプル取り寄せの型

1. 目的（量産評価 / 写真撮影 / テスト販売）
2. 必要数・必要仕様・必要期限
3. サンプル料金負担の条件
4. 評価観点（品質・寸法・色ブレ・梱包・同梱物）
5. 評価結果記録（再発注判断のログ）

---

## 6. 在庫管理の基本

- ABCランク管理（売上上位品ほど在庫多め）
- 在庫回転日数の目標設定（ジャンル別）
- 欠品損失と過剰在庫のコストを比較判断

---

## 7. NGパターン

- 「感覚的にイケそう」という理由だけで仕入れる
- 原価計算に送料・手数料を含め忘れる
- MOQに合わせて過剰仕入れ
- サンプル評価なしで量産発注
- 法規制チェック漏れ

---

## 8. 運用ルール

- 仕入れ判断結果（採用・不採用・要継続検討）を `outputs/procurement/` に蓄積
- 採用後の実績（販売数・回転日数・クレーム率）を3ヶ月後に振り返る
- 教訓は本ファイルに追記
