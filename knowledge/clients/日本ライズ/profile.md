## 4. 提案方針（現時点の戦略）

### 全体の考え方

1. **まず露出 → 実績 → SEO → 広告脱却**の順
2. 「検索に埋もれている」商品 → **アイテムリーチ**で露出作る
3. 「ある程度自然検索で上位」商品 → **PRオプション**（段階的に%引き上げ）
4. 初期は利益より売上重視、販売実績ができれば価格調整の幅が広がる

### 現在のアイテムリーチ設定（2026/4時点）

- メッシュクロスCPC：40円
- その他雑貨商材：30円（ただし赤字商品は除外検討中）
- 日額予算：1,500円（最低）
- ブースト：5のつく日 / 日曜日 / 爆買week（17-19日）で +30円

### PRオプション設定

- メッシュクロス：30%（3/10以降）※ 他商品と施策重ねず、効果検証優先
- 霧吹き：20%
