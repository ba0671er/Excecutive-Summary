# 立花さんの提案パターン集（日本ライズ様向け）

> 立花さんが日本ライズ様に対してどう提案を組み立てているかの構造・思考フレームを抽出。
> 今後の提案作成時のリファレンス。

---

## 0. 粒度ルール（提案の種類ごとの長さ・重さ）

代表指示（2026-04-23）に基づき、提案は目的別に粒度を使い分ける：

| 種類 | 分量目安 | 含める要素 |
|------|---------|-----------|
| **週次・日次の軽い提案** | A4半分以内 | ハイライト1段落 + 施策3〜4件（数値のみ）+ 確認事項2〜3点 |
| **月次定例用の提案** | A4 1〜2枚 | 現状分析 + シミュレーション + 施策5件前後 + 確認事項 |
| **キックオフ・戦略見直し** | フル版 | 診断 + KPI + ロードマップ（`templates/strategy-deck.md`準拠）|

### 週次提案のテンプレ（簡潔版）

```
お世話になっております。
[今回のテーマ]をご提案させていただきます。

■ハイライト
[1段落：今週/今期で一番大事な事実を1〜3行]

■ご提案
①[施策名]
[具体数値1〜2行]

②[施策名]
[具体数値1〜2行]

③[施策名]
[具体数値1〜2行]

■確認事項
1. [在庫等の質問]
2. [判断が必要な事項]

引き続きどうぞよろしくお願いいたします。
```

**やらないこと**：
- 大きな表を並べる（数字は本文に直接埋める）
- 戦略観の再説明
- 過去経緯の長文
- 「ご参考」「ハイライト」セクションの重複

## 1. 全体戦略観（立花さんの基本思想）

### 販売戦略の順番

```
①アイテムリーチで「見られる」状態を作る
      ↓
②販売実績を積む（初期は利益より売上重視）
      ↓
③SEO・PRオプションで自然検索を上げる
      ↓
④最終的に「広告なしで売れる」状態を目指す
```

**キーワード**：
- 「まずはユーザーに見られるところから」
- 「実績を積めば価格調整の幅が広がる」
- 「広告をかけなくても自然検索流入で売れる状態」がゴール

### 商品の評価軸

1. **価格は勝負できるか**（競合との比較）
2. **露出（検索上位）にあるか**
3. **利益率は何%か**
4. **検索数・競合数の市場規模は？**

## 2. 提案書の構造（メッシュクロス販売戦略 2026/3/17 型）

### ①冒頭：状況分析を1〜2文で凝縮

> 先ず、売れ筋のベンチマーク商品と比較して、価格的には勝負できるが露出が全くできていない状況です。そのため、まずは商品がユーザーに見られるところからとなるため、アイテムリーチの活用をご提案させていただきます。

**型**：
- 競合比較の結論
- 現状の問題点
- それゆえの第一施策

### ②ストーリー：順序立てた説明

> ある程度、検索でヒットするようになればキーワードを分析しSEO対策やPRオプションの活用で自然検索順位を上げていきます。最終的にはベンチマーク商材のように、広告をかけなくても自然検索流入で売れる状態を目指します。

**型**：
- 「今」「次」「最終的に」の3段階で展望を描く

### ③ご提案サマリ：施策を番号つきで列挙

> ご提案サマリ
> ①アイテムリーチ広告の設定。キャッシュバックCPの申込。推奨月額予算2万円。メッシュクロスCPC40円。全品入札30円。超PayPay祭最終2日間（3/21,22）のブーストCPC＋20円。※3/25までに5,000円以上利用が条件のため、米も設定を推奨。※アイテムリーチは実績を見ながら予算・CPCの調整をお願いします。
> ②LINEでの新商品発売の配信(購買率を上げるため、LINE限定クーポン10%の発行)
> ③超PayPay祭最終2日間（3/21,22）の追加ポイントの実施（＋10%）
> ④超PayPay祭最終2日間（3/21,22）のLINE配信

**型ポイント**：
- 1施策につき **数値・条件・注意点** を具体的に
- イベント日（超PayPay祭、爆買week、5のつく日）と紐付ける
- 「※」で補足条件・運用上の注意を明記

### ④締め：相手のアクション喚起

> 各施策の実施可否のご返信とご設定をお願いします。また、ご不明点等ございましたらお気軽にご連絡ください。
> 何卒宜しくお願い致します。

**型**：
- 「返信」＋「設定」の二段で依頼
- 不明点の受け口を提示

## 3. 施策の具体カタログ（実際に提案した施策）

### A. アイテムリーチ広告

- 目的: **露出確保**
- 使い所: 検索に埋もれている商品
- 数値感:
  - 月額予算2万円推奨（Yahoo公式の推奨値）
  - CPC: 商品により30円〜40円
  - 日額予算: 最低1,500円〜通常は0円設定
  - ブースト: 通常日の2.5倍程度が目安
- キャッシュバックCP: 3/25までに税抜5,000円超えの条件などに注意
- ブースト対象日: 5のつく日 / 日曜 / 超PayPay祭 / 爆買week（17-19日）

### B. PRオプション

- 目的: **自然検索順位の引き上げ**
- 使い所: ある程度自然検索で上位にある商品
- 設定: 20% → 効果が弱ければ30%（上限）へ
- 注意: 他の広告施策と重ねると効果検証が困難 → 単独検証推奨

### C. LINE配信 + クーポン

- 目的: **既存客刺激 / 購買率向上**
- セット: 新商品告知配信 + LINE限定クーポン10%
- イベント日（超PayPay祭、爆買week）に配信を合わせる
- Y!ショッピングのLINEテンプレ活用
  - https://store-info.yahoo.co.jp/shopping/knowhow/line/

### D. 追加ポイント施策

- 目的: **転換率のブースト**
- イベント日（超PayPay祭最終2日、爆買week）に +10% など

### E. 無償誘導施策（爆買week特有）

- 商品名末尾に「爆買」を追加
- 商品タグに `bakugai202604` を追加
- 終了後20日午前中に元に戻す

### F. ボーナスストアプラス

- 申込進めて設定内容を立花がレビューする運用

### G. セール価格設定

- 二重価格表示条件: 最低2週間の販売実績が必要
- セール期間の自動切替: 管理機能あり
  - https://store-info.yahoo.co.jp/shopping/toolmanual/dictionary/k/3118.html

## 4. クライアントへの回答の型（Q&A対応）

### 質問が複数並んでいる場合

- **質問ごとに引用 → 回答**の繰り返し構成
- 3/18や4/3の回答が典型例
- 各回答は簡潔に。必要なら補足「〜のやり方の方がよさそうですね」

### 「赤字だから広告やめたい」への返し

**悪い例**（立花さんはやらない）：
- 「はい、やめましょう」で終わる
- 「赤字でもやるべきです」で説得を試みる

**立花さんの実際の返し**：
- 時間軸で展望を示す（「現在の価格でずっと販売し続けるわけではない」）
- 競合の成功事例を具体URL付きで提示
- 「最初は利益より売上」の原則を再確認
- 「現時点で決めるのではなく、動向見つつご提案」で判断タイミングを遅らせる

### 「設定合ってますか？」への返し

- まず「確認します」と一次返信
- 画像添付や具体数値で **画面上の現状** を示しながら修正案を提示
- 設定ミスを責めない

### イベント直前の追い打ち提案

- 「本日5のつく日ですので、転換率は上がりやすい見込みです」のように
  **タイミング理由**と**期待値**を添える
- 小さなご案内でも「よろしくお願いいたします」でしっかり締める

## 6. 提案の時系列パターン（月次リズム）

| タイミング | 提案内容 |
|-----------|---------|
| 月初 | 前月の月次レポート共有 + 当月方針 |
| 5のつく日前後 | ブースト設定推奨（もしくは予算追加） |
| 日曜日 | ブースト対応確認 |
| 超PayPay祭 / 爆買week | 追加ポイント、LINE配信、ブーストCPC+30円、商品タグ |
| 月中（2週目） | 施策の効果検証、微調整 |
| 月末 | 翌月提案・定例MTG予約 |

## 7. 提案作成時のチェックリスト（エージェント向け）

提案文を書く前／書いた後に確認すべきこと：

- [ ] 冒頭は「お世話になっております」か？
- [ ] 状況分析（1〜2文）が冒頭に入っているか？
- [ ] 「今→次→最終」の時間軸ストーリーが描けているか？
- [ ] 提案サマリが**番号付き**で整理されているか？
- [ ] 各施策に**具体数値**（金額、%、日付）が入っているか？
- [ ] イベント日（5のつく日／超PayPay祭／爆買week）と紐付けたか？
- [ ] 「※」で注意点・補足条件を添えたか？
- [ ] 最後に相手の**アクション（返信 / 設定）**を明示したか？
- [ ] 「不明点はご連絡ください」の受け口を入れたか？
- [ ] 締めは「何卒宜しくお願い致します」系で終わっているか？
- [ ] 絵文字・煽り・「絶対」「必ず」を使っていないか？
- [ ] 相手の利益率計算やツッコミに対し、時間軸で返せているか？
