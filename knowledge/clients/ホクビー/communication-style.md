## 2. ホクビー向け立花の文調特徴

### 日本ライズ様と比べた特徴

- **「！」を使う頻度が高い**：「ありがとうございます！」「よろしくお願いいたします！」
- **感情表現がやや濃い**：「ありがとうございました！」「お会いできて〜」「絶対に売れる商品だと確信しました」
- **絵文字は使わない**（先方が使っても立花側は使わない）
- テンポ重視で、作業完了報告は即日〜翌日

### よく使う言い回し（ホクビー頻出）

- 「お世話になっております！」（通常冒頭）
- 「早速ご確認、ご対応頂きまして、ありがとうございます」
- 「対応順次進めてまいります」
- 「情報量多くて恐れ入りますが、下記ご確認いただけますと幸いです」（長文前置き）
- 「引き続きよろしくお願いします！」

### 感情を込めた文章の例（展示会訪問御礼 4/15）

```
実際に試食させていただき、また丁寧にご説明いただいたことで、
商品への理解が非常に深まりました。とても美味しかったです。
〜
絶対に売れる商品だと確信しましたので、しっかりと売上を伸ばせるよう努めてまいります。
```

→ 社外への率直な感情表現もしっかりするのが特徴。関係性構築を重視。

## 3. 稟議依頼の型（大室様向け）

アイテムリーチ予算の稟議依頼（4/2）で示された必須情報：

```
▼概要
[施策の1〜2行説明]

▼詳細資料
[公式マニュアルURL]

▼4月予算
[金額]

▼想定経由売上
[見込み額]

▼運用方針
[商品別のCPC/入札方針・検証ポイント]
```

**型**：項目を「▼」でアイキャッチ、**金額と売上見込みを先に提示**、運用方針で納得感。

## 4. 選択肢を投げて意思決定を引き出す型

商品名編集の権限について（4/2）：

```
■商品名や商品説明について
編集は下記のどれで対応するのがよろしいでしょうか。
①立花で勝手に編集してよい
➁貴社に確認したうえで編集してよい
③提案を作成して貴社で編集していただく
```

→ **3択で抽象度を揃えて**、相手に決めてもらう。結果①で合意。

## 5. 複数名宛の書き方（ホクビー特有）

ほとんどのメッセージが `@戸井弘美 @大室本野` の連名。用件ごとに担当を分けるときは：

```
@戸井弘美 
■[依頼A]
...

@大室本野 
■[依頼B]
...

@戸井弘美 @大室本野 
■[両名確認事項]
...
```

のように **担当ごとブロック化**。板垣様を含める場合は先頭。

## 8. NG：ホクビー様相手に絶対やらないこと

- 担当者を混同する（戸井様＝商品、大室様＝システム・稟議）
- 絵文字で応じる（相手が使っても自分は使わない）
- 感情表現を避けすぎる（FABEX訪問御礼のように熱量を込める場面では込める）
- 稟議に必要な情報を抜く（概要・予算・想定売上・運用方針は必須）
- 板垣様を軽視する（経営層、最終信頼性に関わる）
