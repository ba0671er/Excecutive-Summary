## 4. 提案方針（現時点の戦略）

### 中心テーマ

**「業務用メーカーの確かな商品力を、B2Cにどう届けるか」**
- 商品自体は日本人の1/3が食しているほどの規模感
- 問題は**ブランド知名度×BtoC向け露出**
- 検索露出（アイテムリーチ・SEO）→ 商品ページ改善 → リピート施策（LINE） の順で攻める

### 現在の主要施策

| 施策 | 状況 |
|------|------|
| アイテムリーチ運用（商品ページ改修済み「ありがとうハンバーグ」はCPC100-150円） | 4月9万円、5月15万円（稟議済） |
| 商品名変更（競合リサーチ+市場KW構成、末尾「爆買」無償誘導タグ） | 4/6〜4/16で全商品完了 |
| 商品画像・バナー改修（さとふる画像活用、テキスト占有率20%以下遵守） | ありがとうハンバーグから順次 |
| レビュー施策（まとめバナー設置、5月はレビューでハンバーグ1個プレゼント） | 4/14ありがとうバナー追加、5月プレゼント実施へ |
| 爆買WEEK参加（商品名末尾「爆買」+ 商品タグ `bakugai202604`） | 結果: 4/昨日時点「結構売れた」 |
| LINE公式: リッチメニュー自作に差し替え+友だち限定クーポン（店内全品100円オフ） | リッチメニュー4/今日設置済、挨拶メッセージ設定保留中 |
| インフルエンサー施策（Instagram 5名リスト戸井様から提供） | 戸井様→石狩市に2次利用確認中 |

### 商品名・商品ページ編集の権限

- **意思決定フロー①**（4/2合意）：
  1. 立花で編集
  2. ホクビー様でチェック
