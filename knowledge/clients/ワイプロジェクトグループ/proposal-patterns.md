## 0. 粒度ルール（提案の種類ごとの長さ・重さ）

代表指示（2026-04-23）に基づき、提案は目的別に粒度を使い分ける：

| 種類 | 分量目安 | 含める要素 |
|------|---------|-----------|
| **週次・日次の軽い提案** | A4半分以内 | ハイライト1段落 + 施策3〜4件（数値のみ）+ 確認事項2〜3点 |
| **月次定例用の提案** | A4 1〜2枚 | 現状分析 + シミュレーション + 施策5件前後 + 確認事項 |
| **キックオフ・戦略見直し** | フル版 | 診断 + KPI + ロードマップ（`templates/strategy-deck.md`準拠）|

成田様はテンポ早いタイプのため、**週次提案は特に短く**。スクショで済むものはスクショ優先。

## 1. 戦略観（基本思想）

日本ライズ様と同じく **「まず露出 → 実績 → SEO → 広告脱却」** の4段階。
加えてワイプロ様（牧草EC）では以下を重視：

- **リピート商材である前提**（消耗品）
- **流入数の絶対数不足が最大課題**（同カテゴリ他ストア比）
- **配送（楽天ロジ）の構造問題**を前提に、配送以外の打ち手で勝ちに行く
- **在庫（特に食べ比べ）連動**で売上が止まる

## 3. 売上目標の分解パターン（4/23の実例）

4月売上目標20万を達成するため：

```
平日平均 5,000円 × 〇日 = 合計3万円
5のつく日、日曜日 平均1万円 × 〇日 = 合計2万円
追加施策で +1万円 = 合計1万円（+α）
---
合計20万を狙う
```

**型**：
- **日別レートで分解**（平日 / イベント日 / 特別日）
- **「これくらいのペースで売上を作りたい」という意味**と添える
  - 成田様から「これはブーストですか？」と勘違いされたので、**意図を一言付加**

## 4. 施策カタログ（ワイプロ適用版）

### A. アイテムリーチ（通常 + ブースト）

- 通常: 5のつく日・日曜日・爆買week で +30円
- 追加ブースト: 日予算5,000円、入札価格+100円（重要セール日）
- 28-29日（5月）: ポイント狙いユーザー増加日、ブースト推奨

### B. SEO対策（商品名）

- 主力KW: 「チモシー 一番刈り うさぎの餌 牧草 オーツヘイ」
- 商品名の **先頭** に入れる
- 対象商品のみ（該当性のない商品は不要）

### C. レビューアッププログラム

- インセンティブ: **テキスト50pt / 画像70pt / 動画90pt**（合計210pt以上が条件）
- 初期は全商品設定OK
- 運用の節目：
  - お試しで20件、その他は5件くらい集まったら個別商品設定へ
- 個別商品登録CSV形式：A列=商品ID / B列=テキストpt / C列=画像pt / D列=動画pt / E列=stop件数

### D. クーポン（4/23 振り返り結果・5月提案）

**4月の結果**：
- 爆買week 20%オフ → 新規訪問数は伸長、獲得30枚/利用10枚
- 購買率は伸びきらず（流入増についていかず）

**5月への改善案**：
- ①事前獲得促進（セール1週間前にクーポン発行）
- ②割引率引き上げ（50%オフ検討）
- 28-29日のポイント+11%（チャーム17%超えを狙って18%）

### E. ボーナスストアプラス

- 5月は全日程参加基本
- 5% vs 10% の検証：
  - 5のつく日・日曜日・平常日の伸長率を比較
  - 3月時点では有意差小さい、サンプル増やして継続検証
- ウルトラ爆買week期間（5/30-6/1）は半額クーポン併用なら5%、単独なら要検討

### F. 優良配送（構造問題あり）

- 楽天ロジ + BOSSで日付指定なし注文は最大4日後発送
- 優良配送要件（遅延率5%以下）を満たしづらい
- 現在は「指定を促す」設定、遅延監視中
- 問題継続なら3択（広告注力 / Yahoo自社配送 / RMS変更）

### G. 爆買week無償施策

- 商品名末尾に「爆買」を追加（商品タグ `bakugai202604` と **セットで必須**）
- 終了後（20日午前中）に元に戻す
- 商品タグが使えない場合は無償誘導の対象外

## 5. 現状分析の観点（同カテゴリ他ストアとの比較軸）

立花さんがワイプロ様の現状診断で使った4軸：

| 軸 | 目的 |
|----|------|
| **流入数**（検索 / 商品詳細 / 外部） | そもそも見られていないかの把握 |
| **優良配送** | 配送品質バッジの有無 |
| **レビュー数** | 信頼指標・SEO効き |
| **クーポン利用注文数** | 販促インパクトの効き方 |

これらで **差分が大きい指標** を「対策の中心」として提示するのが立花流。

## 6. 在庫連動の重要性（牧草EC特有）

- 食べ比べ商品は「サンプル入口」→ 在庫切れ=新規機会損失
- 提案書の末尾に**確認事項として在庫状況を問う**スタイル
  - 実例（4/2）: 「現状、食べ比べが在庫切れになっていますが、在庫復帰はいつくらいになりそうでしょうか？」

## 7. 振り返り提案の型（4/23の実例）

```
[施策名]の振り返りとご提案です。
・[良かった指標1]
・[良かった指標2]
・[課題指標]

次回に向けてですが、下記2点対策できればと考えています。
期間と割引率は在庫状況でご相談させてください。
①[改善策1]
➁[改善策2]

よろしくお願いいたします。
```

**型ポイント**：
- **箇条書きで結果を3点凝縮**（良い1-2点 + 課題1点）
- **次回への改善案を2点**
- **在庫等の前提条件**を相手に確認
- スクショを画像添付

## 8. 提案作成時のチェックリスト

提案文を書く前／書いた後に確認すべきこと：

- [ ] 冒頭「お世話になっております」＋（CC相手）明示
- [ ] 現状分析を **同カテゴリ他ストア比較** で入れる
- [ ] シミュレーション・目標 をパートナーシートと紐付ける
- [ ] 施策は **差分指標ごと** に対応させる
- [ ] 各施策に **具体数値**（金額・%・日付）
- [ ] 売上目標を **日別レート**で分解して示す
- [ ] **在庫確認・稼働状況**の宿題を末尾に
- [ ] 成田様がスクショで理解できる手順になっているか
- [ ] 「ご不明点はお気軽にご連絡ください」で受け口
- [ ] 長い敬語の連鎖になっていないか（テンポ重視）
