## 4. 提案方針（現時点の戦略）

### 立花さんの基本スタンス

「まず露出 → 実績 → SEO → 広告脱却」の4段階戦略（日本ライズ様と同じ）。
ただし、ワイプロ様は **牧草EC=リピート商材** のため、
- 新規獲得×リピート最大化の両輪
- 優良配送の構造問題を踏まえ、配送以外で勝てる施策を優先
- 在庫連動（特に食べ比べサンプル）が売上に直結

### 現在の主要施策

| 施策 | 状況 |
|------|------|
| アイテムリーチ（5のつく日/日曜/爆買week+30円ブースト） | 設定済み |
| アイテムリーチ追加ブースト（日予算5,000円, 入札+100円） | 爆買week等で設定 |
| SEO対策（商品名に「チモシー 一番刈り うさぎの餌 牧草 オーツヘイ」を前置） | 設定済み |
| レビューアッププログラム（テキスト50pt/画像70pt/動画90pt） | 設定済み・まずは食べ比べレビュー集め |
| 優良配送設定 | 設定済だが遅延リスクあり・運用要調整 |
| ボーナスストアプラス5月申込 | 全日程参加済（5%/10%検証中） |
| 爆買week 20%オフクーポン（4/17-19） | 実施完了・振り返り中 |

### 5月以降の予定施策

- ボーナスストアプラス5月: 全日程参加（5% / 一部10%で検証）
- ウルトラ爆買week（5/30-6/1）: 50%オフクーポン検討（在庫状況次第）
- セール前1週間の事前クーポン発行
- 28-29日ポイント+11%（プレミアム倍率でチャーム超えを狙う）
