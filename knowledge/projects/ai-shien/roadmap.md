# AI導入支援事業 ロードマップ（たたき台）

> 対象: 立花・浦川 の二人体制
> 範囲: 体制構築 〜 初回企業研修の実施まで
> 期間想定: **約6ヶ月**（要調整）
> 作成日: 2026-04-25
> 状態: たたき台。確認事項を踏まえて改訂予定

---

## 0. 二人の特性整理（役割分担の前提）

| 観点 | 立花 | 浦川 |
|------|------|------|
| **稼働時間** | フルタイム | 副業（本業優先・週夜＋週末） |
| **実務経験** | ECコンサル／自社EC運用／AI実装 | 生産性向上PJ 3年 |
| **AI支援事業者の登録要件** | クリア困難（実務経験10年要件） | **クリア可能性高（生産性PJ実績で例外要件）** |
| **対外的な動き** | 営業・クライアント対応・実装 全部可 | Yahoo所属で動きに制約／副業申請でAI支援名義はOK |
| **強み領域** | 提案／実装／クライアントワーク／SNS発信 | プロセス整理／業務フレーム／Yahoo人脈／コンテンツ設計 |
| **集客チャネル** | クラウドワークス／展示会／自社EC関連／x発信 | ECパイロット経由（約5万社）／Yahoo関連の場 |

### 役割分担の基本原則
- **対外（営業・受注・実装・SNS）= 立花**
- **裏方（制度クリア・コンテンツ設計・プロセス整理）= 浦川**
- **講師業は両者で**（立花メイン進行、浦川は専門知識補助）

## 1. ロードマップ全体像（6ヶ月想定）

```
M1            M2            M3            M4            M5            M6
[Phase 0]──────┐
体制・制度    │
              [Phase 1]──────────┐
              実績作り(1〜2社)   │
                                  [Phase 2]──────────┐
                                  事例化・登録申請    │
                                                      [Phase 3]─────
                                                      集客・初回研修
```

| Phase | 期間 | ゴール |
|-------|------|--------|
| **0. 体制・制度** | M1（1ヶ月）| 法的・契約・登録要件をクリアし動ける状態に |
| **1. 実績作り** | M1.5〜M3 | 1〜2社で無料／低額の導入支援を完遂し事例化 |
| **2. 事例化・登録** | M3〜M5 | パッケージ化／研修コンテンツ／AI導入支援事業者登録 |
| **3. 集客・初回研修** | M5〜M6 | 受講者10名以上の有料企業研修を初回実施 |

## 7. 早期に進めたい「最初の3アクション」（来週〜10日以内）

1. **立花**: 社労士に登録要件をヒアリング（複数当たる）
2. **浦川**: 副業申請のステータス確認（AI支援名義で更新）と、生産性PJ実績の証明書類着手
3. **両者**: 利益配分のたたき台を出して合意（次回MTGで議題化）

この3つが詰まらないと他が進まないため、Phase 0で最優先。

## 8. リスクと対応

| リスク | 影響 | 対応 |
|--------|------|------|
| 浦川の登録要件NGだった | Phase 2で詰まる | 早期に社労士ヒアリングで確実化（0-1） |
| 浦川の副業申請が通らない | 事業継続不可 | 0-7で確実化／代替案として立花単独事業＋浦川は外部講師契約 |
| 利益配分で揉める | プロジェクト解散 | 0-8で書面合意 |
| パイロット先が見つからない | 事例化遅延 | 立花の既存EC客に頭打診を早めに（1-3） |
| 補助金制度の改正 | ビジネスモデル崩壊 | 補助金以外の有料研修プランも並行設計 |
| 情報漏洩事故 | 信用失墜・賠償 | 0-6で保険／契約書で責任分担 |
