# クリエイティブ制作部門 ルーター

## 部門ミッション
商品ページ、LP、バナー、広告文のコピーライティングと、デザイン制作ディレクション。
「つくりての想い」を消費者に届ける表現をつくる。

## 所属エージェント

| エージェント | ファイル | 担当 |
|------------|---------|------|
| コピーライター | `agents/creative/copywriter.md` | キャッチコピー、広告文、商品説明文 |
| デザインディレクター | `agents/creative/designer-director.md` | バナー・LP構成案、デザイン指示書 |

## ルーティング指針

| ユーザー依頼の例 | 起動エージェント |
|-----------------|-----------------|
| 「商品ページのコピー」「広告文案3パターン」 | copywriter |
| 「バナーの構成案」「LPのワイヤー」 | designer-director |
| 「新商品のLP一式」 | copywriter と designer-director を **並列** 起動 |
